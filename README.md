# Ashgabat Events — Telegram-бот афиши

Показывает события с сайта [ashgabatevents.com](https://www.ashgabatevents.com) в Telegram:
кнопки «Сегодня» / «Выходные» / «Эта неделя» / категории, подписка на ежедневную подборку,
`/stop` для отписки. Бот не хранит переписку — только `chat_id` подписчиков и дату последней
отправленной подборки. Новости и реклама не показываются — только события с сайта.

## Требования
- Python 3.13 (или 3.12)
- Токен бота из [@BotFather](https://t.me/BotFather)

## Установка
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env             # и вписать BOT_TOKEN
```

## Настройки (`.env`)
| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `BOT_TOKEN` | да | — | токен от @BotFather |
| `FEED_URL` | нет | `.../api/public/v1/events` | откуда брать события |
| `TIMEZONE_NAME` | нет | `Asia/Ashgabat` | часовой пояс для «сегодня», «выходные» и времени дайджеста |
| `DIGEST_TIME` | нет | `09:00` | локальное время ежедневной подборки |
| `FEED_TTL_SECONDS` | нет | `300` | как долго кэшировать ответ сайта |
| `DB_PATH` | нет | `data/bot.sqlite3` | путь к файлу базы подписчиков |
| `LOG_LEVEL` | нет | `INFO` | `DEBUG` не использовать на реальных данных — в лог попадают апдейты целиком |
| `PROXY_URL` | нет | — | только для разработки, если `api.telegram.org` недоступен напрямую; на сайт заказчика не влияет |

Переменная называется `TIMEZONE_NAME`, а не `TZ`: `TZ` зарезервирована операционной системой,
и в контейнере там часто стоит `UTC` — с таким именем дайджест мог бы незаметно уйти не в то время.

## Запуск

### Локально
```bash
python -m bot.main
```
Остановить: `Ctrl+C`. При старте бот снимает вебхук и переходит на polling — входящие порты
открывать не нужно, достаточно исходящих соединений к `api.telegram.org` и к сайту заказчика.

### Docker
```bash
docker compose up -d --build
docker compose logs -f bot
```
Файл `.env` должен лежать рядом с `docker-compose.yml`. Данные (`data/bot.sqlite3`) хранятся
в volume `./data` — при пересборке контейнера подписчики не теряются. Контейнер работает от
непривилегированного пользователя, не от `root`.

## Как это устроено
- **Данные.** Бот ничего не хранит из ленты: по каждому нажатию кнопки запрашивает сайт
  (`when=today|weekend|week|...`, `category=...`), результат кэширует на `FEED_TTL_SECONDS`
  (по умолчанию 5 минут), чтобы не нагружать сайт частыми нажатиями.
- **Категории.** Отдельного запроса за списком категорий в API нет — бот собирает их из самих
  событий (`bot/ordering.py: collect_categories`), по убыванию числа событий.
  При нажатии на категорию бот показывает все ближайшие события этой категории, без привязки
  к периоду (заказчик может попросить это изменить — правится в `bot/service.py`).
- **Повторяющиеся события.** У них общий `series_key`; бот показывает только первое в серии
  (`bot/feed.py: first_of_series`), чтобы «CrossTalk Debate» не занимал по строке на каждый
  четверг.
- **Ежедневная подборка.** Планировщик проверяет каждые 10 минут, не настало ли время
  дайджеста (`DIGEST_TIME`). Внутри трёхчасового окна после этого времени подборка либо уже
  отправлена (`last_sent_date` в базе — повторно не шлём), либо отправляется сейчас, либо, если
  сайт в этот момент недоступен, будет отправлена при следующей проверке. Если на сегодня нет
  ни одного события, бот молчит, но отмечает подписчиков как обработанных на сегодня.
- **Устаревшие сообщения.** Кнопки под сообщением дайджеста живут в чате днями. Если сообщение
  старше 48 часов, Telegram не даёт его отредактировать — бот присылает экран новым сообщением
  вместо того, чтобы упасть с ошибкой.

## Обслуживание
- **Бэкап.** Это один файл `data/bot.sqlite3`. Для бэкапа без остановки бота:
  `sqlite3 data/bot.sqlite3 ".backup data/backup.sqlite3"`.
- **Посмотреть число подписчиков:**
  `sqlite3 data/bot.sqlite3 "SELECT COUNT(*) FROM subscribers;"`
- **Обновление кода.** После `git pull` — `pip install -r requirements.txt` (если менялись
  зависимости) и перезапуск процесса/контейнера. Схема базы создаётся автоматически при
  первом запуске (`CREATE TABLE IF NOT EXISTS`), накатывать миграции вручную не нужно.
- **Токен скомпрометирован.** В @BotFather: `/revoke`, получить новый, обновить `.env`,
  перезапустить бота.

## Если сеть мешает (разработка)
Если `api.telegram.org` недоступен напрямую из вашей сети, но доступен через прокси — укажите
`PROXY_URL` в `.env` (например, `http://127.0.0.1:8080`). Запросы к сайту заказчика прокси
не используют, идут напрямую.

## Тесты
```bash
pip install -r requirements-dev.txt
pytest -q
```
Весь функционал покрыт тестами без обращения к интернету (ответы сайта и Telegram подменены
фикстурами). Перед релизом также стоит прогнать `pip-audit` и `bandit -r bot` — см.
`SECURITY_NOTES.md`.
